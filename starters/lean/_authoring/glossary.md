# Glossary

The terms of the website in each of its languages. Add a column for each further language of `site.languages`.

| English | Deutsch | Note |
| --- | --- | --- |
| page | Seite | A Markdown file in `pages/` |
| post | Beitrag | A Markdown file in `posts/`, dated |
| doc | Dokument | A Markdown file in a book, such as `book/` |
| book | Buch | A directory of docs that `books` in `blyss.config.js` names |
| draft | Entwurf | `draft: true` |
| contribution | Beitrag im Wechsel | A turn of a human or an agent, `{contribution}` |
| AI agent | KI-Agent | The label of an agent's contribution |
